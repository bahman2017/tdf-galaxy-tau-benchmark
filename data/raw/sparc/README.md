# SPARC Raw Data Staging

This folder stores raw SPARC rotation-curve inputs for ingestion.

## Scientific provenance

Primary scientific source (citation target):
- SPARC official site: http://astroweb.case.edu/SPARC/
- Lelli, McGaugh & Schombert (2016), *SPARC: Mass Models for 175 Disk Galaxies with Spitzer Photometry and Accurate Rotation Curves*.

## Mirror/cache usage

A local mirror (e.g., `bahman2017/sparc`) may be used only as a transport/cache source for raw `Rotmod_LTG` files.
Do not treat mirror repositories as the scientific citation source.

## Scope boundary

Only raw `*_rotmod.dat` files are ingested in Phase 1A.
No Yukawa/delay fitting scripts, prior fit results, plots, or derived model outputs are used.
