# Data Sources

## Current phase note

Phase 0B uses scaffold and mock-compatible data flow for pipeline hardening only.

**No observational claim can be made from mock data.**

## Planned observational source

- SPARC rotation-curve products in processed CSV form.

## Required unit-explicit columns for processed input

- `galaxy_id`
- `r_kpc`
- `v_obs_kms`
- `v_err_kms`
- `v_gas_kms`
- `v_disk_kms`
- `v_bulge_kms`

## Provenance rule

Any real observational dataset inclusion must include documented source provenance, preprocessing decisions, and versioning notes.
